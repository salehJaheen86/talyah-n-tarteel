# ترتيل وتالية: الحلقة الثانية

موقع ثابت (HTML) بدون أي برامج. الصفحة الرئيسية: index.html

## النشر على GitHub Pages
1. أنشئ Repository جديد (مثلا tarteel-talyah-ep2) على GitHub.
2. ارفع كل محتويات هذا المجلد في جذر الـ Repository (index.html في الجذر).
3. Settings ثم Pages ثم Build and deployment: اختر Deploy from a branch، الفرع main، المجلد / (root)، ثم Save.
4. بعد دقيقة يظهر الرابط: https://USERNAME.github.io/REPO/
